## Step1 视频提取帧

从源视频 / 目标视频中提取帧画面（**PNG 无损**），并支持按时间段切割、均分分段视频。

### 源视频（SRC） / 目标视频（DST）提取

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 视频路径 | 文本框+浏览 | `workspace/data_src.mp4` / `data_dst.mp4` | 要提取的视频文件，支持 mp4/avi/mov/mkv/flv/webm |
| FPS | 整数 0~120 | 0（显示"原始"） | 提取帧率。0 = 按视频原始帧率提取。**DST 侧锁定为原始 FPS，不可改**（保证与源视频时间轴一致）；SRC 侧可改 |
| 限制解码线程（HDD磁盘建议勾选） | 勾选框 | 关 | 限制 ffmpeg 解码线程数，机械硬盘场景避免解码与写入争抢 IO |
| 开始提取 | 按钮 | — | SRC 帧输出到 `workspace/data_src/`（PNG），DST 帧输出到 `workspace/data_dst/`（PNG） |

### 视频切割（按时间段截取）

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 开始时间 / 结束 | 文本框 | `00:00:00.000` | 切割起止时间（时:分:秒.毫秒格式） |
| 开始切割 | 按钮 | — | 输出为原文件名 + `_cut` 后缀 |
| 均分段数 | 整数 2~100 | 2 | 将视频按时长均分为 N 段 |
| 开始分割 | 按钮 | — | 输出为原文件名 + `_seg1`、`_seg2`… 依序分段 |

### 输出日志

面板底部黑底滚动日志区，实时显示 ffmpeg 提取 / 切割进度与结果。

## Step2 人脸提取

从提取的帧中检测并对齐人脸（InsightFace SCRFD 检测 + 106 点 landmark 对齐），输出到 `data_src/aligned`、`data_dst/aligned`。

### 检测设备

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| GPU | 下拉框 | 有 GPU 时自动选第一个 GPU | 选项：`CPU`、`[CUDA:i] 显卡名`、`[XPU:i] 显卡名`（按实际可用设备枚举）。提取使用 onnxruntime 的 CUDA 执行提供程序 |
| 多GPU并行（使用所有可用GPU） | 勾选框 | 关 | 当前**隐藏**（`setVisible(False)`）。需 ≥2 张 GPU 才可勾选，勾选后并行使用所有可用 GPU |

### 人脸提取参数

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 人脸类型 | 下拉框 | whole_face | `whole_face`（宽全脸，默认输出 512）、`head`（含头发，默认输出 768）。**切换会自动联动"图像尺寸"为对应默认值** |
| 最大人脸数 | 整数 0~100 | 0 | 每帧最多提取的人脸数。0 = 不限 |
| 检测阈值 | 小数 0.1~1.0（步进 0.05） | 0.5 | SCRFD 人脸检测置信度阈值，越低检出越多但误检越多 |
| 图像尺寸 | 下拉框（可编辑） | 512 | 预置 512/768/384/256/640/1024/128/896，可手动输入 64~4096 的任意整数 |
| 输出格式 | 下拉框 | jpg | `jpg` / `png` |
| JPEG 质量 | 整数 1~100 | 100 | 仅 jpg 格式生效 |
| 输出调试图像到 aligned_debug | 勾选框 | 开 | 在 `data_dst/aligned_debug` 输出带检测框/特征点/人脸的调试图（SRC 也输出到 `data_src/aligned_debug`） |

### 提取与预览按钮

| 按钮 | 说明 |
|------|------|
| 开始提取 | 检测+对齐+生成元数据（每张图生成同名 `.json`：检测框 bbox、kps 5 点、106 点、姿态等）。已有文件时弹窗确认覆盖 |
| 预览生成 | 打开调试图预览窗口（DebugPreviewDialog），查看并编辑特征点 |
| 删除头像 | 打开删除头像窗口（FaceDeleteDialog），可浏览/勾选/右键删除对齐图，支持相似度排序 |
| 分析头像 | 打开状态分析窗口（StateAnalysisDialog），按 yaw/pitch 网格 5° 分析人脸姿态覆盖 |

### 源目标（SRC）工具栏

| 按钮 | 说明 |
|------|------|
| 去重过滤 | 打开去重对话框（SrcDedupDialog）：基于 **3DDFA 状态去冗余**——按角度/表情/光照/roll 参数保护全覆盖，同状态冗余时保留清晰度最高者（Tenengrad），大面积遮挡图排除在可删除之外；姿态优先读元数据 pose，3DDFA 仅作兜底 |
| 批量重命名 | 将 `data_src/aligned` 中所有图（含 .json）按文件名排序后重命名为 `00001_0`、`00002_0`… 连续编号 |

### 标注与训练

| 按钮 | 说明 |
|------|------|
| 手动标注 | 打开手动标注窗口（ManualAnnotatorDialog）：对无元数据图片手动标注 5 点/106 点，生成头像与元数据；已有点时可修正 |
| IF训练 | 跳转到 step7（InsightFace 检测器/landmark 模型训练页） |

### 排序筛选

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 排序目标 | 单选 | 源人脸 (SRC) | 对 `data_src/aligned` 或 `data_dst/aligned` 排序 |
| 排序算法 | 单选按钮组 | blur | `blur`模糊度 / `hist`直方图相似 / `yaw`偏航角 / `pitch`俯仰角 / `brightness`亮度 / `hue`色调 / `oneface`单人筛选（只保留每帧最大人脸并删除其余）/ `final`综合排序 |
| 排序 | 按钮 | — | 按所选算法重排目标目录文件名（同步更新文件名与元数据映射，重建 `_source_index.json`）。运行期间该界面所有按钮禁用 |

## Step3 遮罩 XSeg

编辑、训练和应用 XSeg 人脸遮罩（遮罩以多边形形式保存进人脸元数据）。

### 遮罩编辑

| 控件 | 说明 |
|------|------|
| 源人脸（data_src）/ 目标人脸（data_dst） | 选择编辑目标目录 |
| 打开遮罩编辑器 | 打开 XSeg 编辑器（XSegEditorDialog）。**打开期间主窗口禁用**，防止重复多开；关闭后恢复 |
| 提取已标注 | 将标注过人脸的图整理/提取（fetch_annotated） |
| 清除标注 | 确认后清除目标目录中所有 XSeg 标注 |

### 遮罩训练

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 脸部类型 | 下拉框 | wf | `wf`(256×256) / `head`(384×384)。**应与提取时一致** |
| 批次 | 整数 1~64 | 4 | 每步训练样本数。RTX 4090 建议 4~8 |
| 迭代 | 整数 0~10000000（步进 10000） | 0 | 总训练迭代数。**0 = 无限训练（手动停止，与 DFL 一致）**；遮罩通常 5~10 万次收敛 |
| 混合精度 | 下拉框 | fp16 | fp32 / fp16（推荐）/ bf16（易梯度爆炸，不推荐） |
| 学习率 | 小数 1e-6~1e-2（步进 1e-5，6 位小数） | 1e-4 | DFL 默认 1e-4，通常 1e-4~5e-5 |
| 预训练 | 勾选框 | 关 | 先 DSSIM+MSE 灰度图自重建预训练（skip=zeros_like），再 BCE 微调 mask 分割。**建议首次训练开启；一旦退出预训练模式则锁定不可回退**（防止误开破坏已训练模型） |
| lr_dropout | 小数 0~1（步进 0.1） | 0.3 | 每步以该概率将梯度置零（随机正则化）。0=关闭，0.3=DFL 默认；训练后期开启可获更锐利结果 |
| 开始训练 / 停止训练 | 按钮 | — | 训练数据为 `data_src/aligned` + `data_dst/aligned`，模型存 `workspace/model/xseg/`，配置存 `XSeg_config.json`；预训练数据用 src aligned |
| 训练日志 | 只读文本框 | — | 实时迭代 loss |

训练预览窗口快捷键：`Space` 切换 preview 页、`P` 刷新、`S` 保存、`L` 循环 loss 范围、`Enter` 保存并停止。

### 遮罩应用

| 控件 | 说明 |
|------|------|
| 源人脸 / 目标人脸 | 选择应用目标目录 |
| 应用训练遮罩 | 用训练好的 XSeg 模型对目标目录所有人脸生成遮罩并写入元数据 |
| 移除训练遮罩 | 确认后移除目标目录中所有训练遮罩 |
| 应用通用遮罩 | 弹出选择框：`DFL遮罩`（推荐）/ `Face Parsing`（很慢）/ `SAM3`（很慢），对每张人脸运行所选方法生成多边形遮罩写入元数据 |

## Step4 训练

换脸模型训练入口：选择模型类型与参数，训练特定人物对模型。

### 模型类型

`SAEHD` / `AMP` / `Quick96` 三个单选按钮。切换时下方参数面板整体重建为对应模型的参数组。

### 模型名称选择器

- 选择/新建模型目录：模型根目录按类型为 `workspace/model/saehd`、`workspace/model/amp`、`workspace/model/quick96`
- **新建模型**：输入名称；SAEHD 保存目录名自动追加架构后缀（如 `MyModel_df`）；若同名目录已有权重会弹窗提示"清空旧权重"或重命名
- **复用已有模型**：加载该目录的配置文件恢复参数，继续训练
- 配置文件：GUI 面板读/写 `{模型目录}/{类型}_training_config.json`（如 `SAEHD_training_config.json`）；点击开始训练时同步写入模型目录内的 `training_config.json`，供 step5 合成加载

### 参数面板（SAEHD 八组）

按 `SAEHD_SUBGROUPS` 分为八组展示：模型架构 / 优化器与学习率 / 数据增强 / 人脸细节 / 损失函数 / GAN 对抗 / 训练控制 / 数值稳定性与显存。每组参数详解见《SAEHD 训练参数详解》。

面板内的参数联动行为：

| 联动 | 行为 |
|------|------|
| face_type ↔ resolution | 切换 face_type 自动设置默认分辨率：wf=256、head=384 |
| archi 后缀 d/t ↔ resolution | 含 `d`（分辨率倍增）或 `t`（深层）时，分辨率步进与对齐单位改为 32 倍数 |
| archi 过滤 | `true_face_power` 仅 `df` 架构显示；切换为 liae 自动隐藏 |
| 架构锁定 | 模型已初始化后锁定：SAEHD 锁 `resolution/face_type/archi/amp_mode/ae_dims/e_dims/d_dims/d_mask_dims/gan_patch_size/gan_dims`；AMP 额外锁 `inter_dims/morph_factor`；Quick96 仅锁 `amp_mode`。锁定项灰色不可改 |
| pretrain 退出锁死 | 预训练模式一旦退出（config 中 pretrain=False），`pretrain` 勾选框禁用不可回退（SAEHD/AMP） |

### 训练控制

| 控件 | 说明 |
|------|------|
| 开始训练 | 校验 `data_src/aligned` 与 `data_dst/aligned` 均 ≥1 张（<4 张时弹窗询问是否继续）。运行后该界面所有按钮禁用，仅"停止"可用（变红） |
| 停止 | 请求停止训练，保存当前权重 |
| 训练日志 | 黑底滚动日志：`[时间][#迭代][单次耗时][src loss dst loss][D_gan]`；每 0.5s 节流刷新 |
| 状态栏 | 迭代号 / 平滑损失 / 总耗时（运行中进度条脉冲） |
| 训练预览窗口 | 实时预览（SAEHD/AMP），快捷键：`Space` 切换 section、`P` 刷新、`S` 保存 checkpoint、`L` 循环 loss 显示范围、`Enter` 保存并停止 |

## Step5 合成融合

实时预览换脸效果，调整遮罩与颜色迁移参数，合成全部帧。

### 模型选择

| 控件 | 说明 |
|------|------|
| 类型 | SAEHD / AMP / Quick96 |
| 名称 | 扫描对应模型目录下含 `training_config.json` 或 `SAEHD_training_config.json` 的模型目录。**切换到此面板时自动刷新列表**（不打断已加载模型） |
| 加载模型 | 后台加载权重并自动渲染当前帧。切换类型会释放已加载模型并清显存 |
| 模型状态 | 未加载 / 加载中 / 已加载: 名称 / 加载失败原因 |

### 合成参数

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 遮罩模式 | 下拉框 | xseg | `xseg`(用XSeg遮罩) / `dst`(原图遮罩) / `learned`(模型训练遮罩) / `learned-prd` / `learned-dst` / `learned-prd*dst`(前两者相乘) |
| 遮罩侵蚀 | 小数 -400~400 | 0 | 正=收缩遮罩，负=扩大遮罩 |
| 遮罩模糊 | 小数 0~400 | 20 | 遮罩边缘模糊半径 |
| 颜色迁移 | 下拉框 | none | 合成时颜色迁移：`none` / `rct` / `lct` / `mkl` / `idt` / `sot`（**仅 6 项，训练 ct_mode 是 8 项**） |
| 人脸缩放 | 小数 -50~50 | 0 | 正=放大换脸区域，负=缩小 |
| 人脸增强 | 下拉框 | (无) | `(无)` / `gfpgan_1.4` / `gpen_bfr_512` / `gpen_bfr_1024` / `restoreformer_pp` |
| 增强混合 | 整数 0~100 | 80 | 增强结果与原结果的混合比例 |

参数变更后 300ms 防抖自动重渲染当前帧。

### 帧导航与合成

| 控件 | 说明 |
|------|------|
| 帧滑块 / 上一帧 / 下一帧 | 切换当前预览帧（data_dst 中的图片） |
| 帧信息 | `当前/总数  文件名`；状态栏显示 `帧 i/n | k 人脸 | 宽x高` |
| 合成全部帧 | 对 data_dst 所有帧批量合成，输出 `workspace/data_dst/merged/`；进度条 + 停止按钮 |
| 停止 | 请求停止批量合成 |

**快捷键**（需面板获得焦点）：`W`/`S` 侵蚀 ±1，`E`/`D` 模糊 ±1，`T`/`G` 人脸缩放 ±1。

## Step6 导出视频

将合成后的帧（data_dst/merged）转换为带音频的输出视频。

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 输出格式 | 下拉框 | mp4 | `mp4` / `avi` / `mov` |
| 帧率 | 整数 0~120 | 0 | 0 = 自动检测（从源视频读取帧率） |
| 无损输出 | 勾选框 | 关 | 无损编码（文件大） |
| 开始 / 停止 | 按钮 | — | 输出到 `workspace/result.{格式}`，自动从源视频提取音频合并 |

## Step7 IF 训练

先训练 SCRFD 检测器，再训练 106 点 landmark 模型；导出 ONNX 替换 insightface 预训练权重。

### 数据集

| 控件 | 说明 |
|------|------|
| 数据集 | `manual_annotated`（`workspace/insightface_train/manual_annotated`，手动标注数据）或 `LaPa`（`workspace/insightface_train/pretrain_faces/lapa_training`） |
| 额外数据集（concat混合训练） | 可添加 WFLW 等数据集目录（自动映射 106 点并屏蔽缺少点的损失）；添加目录 / 移除 |

### 训练选择

| 控件 | 默认 | 说明 |
|------|------|------|
| 训练SCRFD | 勾选 | 训练人脸检测模型 |
| 训练Landmark | 勾选 | 训练 106 点 landmark 模型（至少勾选一个） |

### SCRFD 参数

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 批次 | 整数 1~64 | 8 | 输入 640×640，显存占用大，建议 4~16 |
| 学习率 | 小数 0.0001~1.0 | 0.001 | 微调（加载预训练）默认 0.001；从头训练 0.01（勾选"微调"自动切换） |
| 轮数 | 整数 1~300 | 30 | 每次点击训练训练这么多轮；续训时从上次位置继续 |
| 微调 | 勾选框 | 开 | 加载 SCRFD 预训练权重分阶段训练；勾选+非刚性形变=针对嘴巴变形/遮挡的微调 |

### Landmark 参数

| 控件 | 类型 | 默认 | 说明 |
|------|------|------|------|
| 批次 | 整数 1~256 | 32 | 输入 192×192，建议 32~128 |
| 学习率 | 小数 | 0.01 | 微调 0.01；从头训练 0.1（自动切换） |
| 轮数 | 整数 1~300 | 30 | 同 SCRFD |
| 微调 | 勾选框 | 开 | 三种模式：不勾=从零训练（需数十万~百万级数据）；勾选=刚性微调（加载预训练+分阶段）；勾选+非刚性形变=增加 TPS 形变/嘴部动作/Cutout 遮挡增强 |
| 主Loss | 下拉框 | Wing Loss | `Wing Loss` / `Adaptive Wing Loss`；前 20% 轮数用 Smooth L1 预热 |
| 自动批次探测 | 勾选框 | 关 | 自动探测最大不 OOM 的 batch，结果不超过手动值 |
| 梯度累积 | 整数 1~16 | 1 | 梯度累积步数，等效增大 batch |

### 通用

| 控件 | 默认 | 说明 |
|------|------|------|
| 数据增强 | 开 | 颜色抖动、模糊、翻转、仿射变换 |
| 非刚性形变增强 | 关（仅微调模式可用） | TPS 形变+嘴部大动作+Cutout 遮挡；勾选后自动启用时序跳变检测 |
| 从头训练 | 关 | 删除已训练模型文件从零开始；弹确认，自动取消微调勾选，学习率切 0.1/0.01 |
| 训练后部署到antelopev2 | 关 | 训练结束自动把导出的 ONNX 部署到 antelopev2 权重目录；首次部署永久备份官方权重为 `.onnx.official`（不被覆盖），后续微调始终从 `.official` 加载 |

### 训练控制与预览

- 开始训练 / 停止（停止超时 15s 提示）
- 右侧实时预览：SCRFD 检测预览、Landmark 预览 + 各自 loss 曲线图（每 5s 刷新）
- 配置与状态：`workspace/model/scrfd/SCRFD_config.json`、`workspace/model/if_landmark/IFLandmark_config.json`；训练状态 `*_training_state.json`

## 通用行为说明

### 全局互斥（按钮禁用）

所有面板在任务运行期间采用**全局禁用**策略：点击任一运行按钮后，当前界面所有按钮与参数控件禁用，仅保留：
- 滚动条
- 窗口锁定/关闭
- **停止类按钮**（`busy_keep` 属性，如训练停止、合成停止、导出停止）保持可用并变红

任务结束/失败后全部控件恢复原状。目的：防止运行期间误点其他按钮切换到其他界面或重复触发。

### 面板切换行为

- step4 训练：切换到面板时刷新模型列表并保持当前选择
- step5 合成：切换到面板时刷新模型名称列表（不打断已加载模型）
- step7 IF 训练：面板显示时启动 5s 预览定时器，隐藏时停止
