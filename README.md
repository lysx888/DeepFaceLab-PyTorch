# **DeepFaceLab_PyTorch说明**
因为DeepFaceLab是基于TensorFlow框架，所以我用Pytorch重新开发了一个换脸项目，实现DFL的所有功能。
# **使用说明**
1. 基于insightface实现的人脸提取和对齐等（[insightface](https://github.com/deepinsight/insightface/)）。
2. 遮罩方面涉及多方面，比如说利用了SAM2（[SAM2](https://github.com/facebookresearch/sam2)），SAM3（[SAM3](https://github.com/facebookresearch/sam3)）,语义分割face-parsing。
3. 头像分析等方面利用了3DDFA-V3（[3DDFA-V3](https://github.com/wang-zidu/3DDFA-V3)）
4. 多GPU暂不支持,XPU卡不支持。
